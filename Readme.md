# Cat Energy

Двухстраничный адаптивный интернет-магазин по продаже корма для котов «Cat Energy».

## 🚀 Технологии

В проекте использованы следующие технологии и подходы:

*   **HTML5**: Продвинутая семантика для улучшения доступности и SEO.
*   **CSS3 / SCSS**: Использованы препроцессор Sass для структурирования стилей.
    *   **Flexbox**: Для создания гибкой и адаптивной сетки макета.
    *   **Анимации и трансформации**: Для добавления интерактивности и плавности интерфейса.
    *   **Кастомные свойства (CSS Variables)**: Для удобного управления цветами и размерами.
*   **Адаптивная графика**:
    *   **Retina Display**: Реализована поддержка экранов с высокой плотностью пикселей (Retina) через `srcset` и `x` дескриптор.
    *   **Оптимизация изображений**: Все изображения оптимизированы для веба (форматы JPEG, PNG, WebP) с целью уменьшения веса страниц и увеличения скорости загрузки.
*   **Адаптивная верстка**: Mobile-first подход с использованием медиа-запросов для идеального отображения на всех устройствах.
*   **Сборка проекта**: Для автоматизации использованы **Node.js** и **npm** (включая возможные задачи по оптимизации изображений).
*   **EditorConfig**: Для поддержания единого стиля кода в разных редакторах.
